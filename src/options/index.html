Settings

Automatic ad skipping

Saves automatically for all tabs. Clicks visible, enabled, unobstructed buttons with this exact label, ignoring case and extra whitespace. Independent of highlighting and Auto Scroll.

Auto Scroll configuration

Position measured from the top of the visible page. Matching posts pause when their top reaches this level. Slowdown uses the same level. This preference applies to all tabs and is saved across browser restarts.

Auto-pause colors

Color changes save automatically. Only positive keywords with checked colors trigger auto-pause. With none checked, keywords never pause scrolling. Slowdown uses all positive keyword colors.

Location checkbot

With Pause after positive keyword enabled, pause only on authors whose uploaded account location matches. Unknown authors and other locations keep scrolling. Slowdown remains independent.

Version 1 scout export, up to 5 MiB. Upload replaces the previous scout dataset. Location checks use accountBasedIn, ignoring notes and connection source. Data stays in this browser.

AI keyword discovery

An API key is optional. Profiles, keywords, and highlighting work without one. Suggestions use your selected provider’s API account. Only the seed keywords you submit are sent; webpage text is never sent.
