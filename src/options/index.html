Settings

Auto Scroll configuration

Position measured from the top of the visible page. Matching posts pause when their top reaches this level. Slowdown uses the same level. This preference applies to all tabs and is saved across browser restarts.

Auto-pause colors

Only positive keywords with checked colors trigger auto-pause. With none checked, keywords never pause scrolling. Slowdown uses all positive keyword colors.

AI keyword discovery

An API key is optional. Profiles, keywords, and highlighting work without one. Suggestions use your selected provider’s API account. Only the seed keywords you submit are sent; webpage text is never sent.

Leave blank to keep your saved key. The key is stored locally in this Chrome profile, without encryption, and is not synced or exposed to content scripts. Use this on a trusted device.

Custom models must support structured JSON on the selected provider’s API. Availability depends on your account; choose a predefined model if a custom request fails.

Choose a provider, enter its key, select a model, and save. Blank retains that provider’s key. Switching providers clears an unsaved key; save it first. API billing is separate from ChatGPT and Claude subscriptions.
